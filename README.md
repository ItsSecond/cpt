# Tactical Arena

A lightweight, browser-based tactical shooter prototype inspired by ability-driven 5v5 games.

## How to run

Open `index.html` in your browser. No build step required.

## Gameplay

- Move with **WASD**.
- Aim with the mouse and **Left Click** to shoot.
- **Shift** to dash.
- **Q** drops a smoke screen.
- **E** sends a recon pulse.
